# Spring Blog

Spring Boot와 Mustache로 구현한 블로그 서비스입니다. 회원은 게시글과 댓글을 작성하고, 포인트를 사용해 유료 게시글을 열람할 수 있습니다.

## 주요 기능

| 기능 | 설명 | 상태 |
|---|---|---|
| 회원 가입·로그인 | 이메일 인증을 완료한 뒤 가입합니다. 비밀번호는 BCrypt로 저장하고 세션 기반으로 로그인 상태를 관리합니다. | 구현 |
| 이메일 인증 | SMTP로 인증 번호를 보내고, 5분 안에 확인합니다. 인증한 이메일과 가입 이메일이 일치해야 가입할 수 있습니다. | 구현 |
| 카카오 로그인 | 카카오 OAuth 인가 코드로 로그인하며, 처음 로그인하면 계정을 생성합니다. | 구현 |
| 회원 정보 | 비밀번호와 프로필 이미지를 변경하거나 프로필 이미지를 삭제할 수 있습니다. | 구현 |
| 게시글 | 목록·상세 조회, 검색, 페이지 이동, 작성, 수정, 삭제를 지원합니다. 작성자만 수정·삭제할 수 있습니다. | 구현 |
| 댓글 | 게시글에 댓글을 작성하고 본인이 작성한 댓글을 삭제할 수 있습니다. | 구현 |
| 포인트 및 유료 게시글 | 포인트 충전 API와 포인트를 이용한 유료 게시글 구매를 지원합니다. 구매 내역과 포인트 차감은 함께 처리됩니다. 유료 게시글 가격은 500포인트입니다. | 구현 |
| 관리자 화면 | 관리자 권한이 있는 로그인 사용자만 대시보드에 접근할 수 있습니다. | 구현 |

### 결제·인증 범위

- 포인트 충전은 현재 사용자 포인트를 올리는 내부 API입니다. 외부 PG(PortOne 등)를 통한 실제 카드 결제 연동은 구현되어 있지 않습니다.
- 이메일 인증은 구현되어 있습니다.
- 휴대폰 본인 인증은 구현되어 있지 않습니다.
- `.env.example`의 `PORTONE_*` 항목은 연동을 위한 설정 자리이며, 현재 코드에서 결제 처리에 사용되지 않습니다.

## 기술 스택

- Java 21, Spring Boot 4
- Spring MVC, Spring Data JPA, Mustache
- H2(개발 기본 프로필), MySQL(운영 프로필 설정)
- Gradle
- Gmail SMTP, Kakao OAuth

## 실행 방법

1. Java 21을 준비합니다.
2. `.env.example`을 참고해 프로젝트 루트에 `.env` 파일을 준비합니다. DB, 카카오 로그인, 메일 발송 기능에 필요한 값을 채워주세요. 비밀 값이 들어 있는 `.env`는 공유하거나 커밋하지 마세요.
3. 기본 `dev` 프로필은 H2 메모리 데이터베이스를 사용합니다. 앱을 실행합니다.

```bash
./gradlew bootRun
```

Windows에서는 다음 명령을 사용할 수 있습니다.

```powershell
./gradlew.bat bootRun
```

기본 주소는 `http://localhost:8080`입니다. `dev` 프로필은 서버를 재시작하면 H2 데이터가 초기화됩니다. MySQL을 사용하려면 `DB_URL`, `DB_USERNAME`, `DB_PASSWORD`를 설정하고 적절한 프로필을 선택하세요.

## 주요 경로

| 경로 | 기능 |
|---|---|
| `/` 또는 `/board/list` | 게시글 목록, 검색, 페이지 이동 |
| `/board/{id}` | 게시글 상세 보기 |
| `/join`, `/login`, `/logout` | 회원 가입, 로그인, 로그아웃 |
| `/kakao-login` | 카카오 로그인 시작 |
| `/user/detail` | 내 정보 보기 |
| `/api/email/send` | 이메일 인증 번호 발송 |
| `/api/email/verify` | 이메일 인증 번호 확인 |
| `/api/point/charge` | 로그인 사용자의 포인트 충전 |
| `/admin/dashboard` | 관리자 대시보드 |

## 프로젝트 구조

```text
src/main/java/com/tenco/spring_blog/
├── board/       # 게시글 및 목록·검색
├── reply/       # 댓글
├── purchase/    # 유료 게시글 구매 내역
├── user/        # 회원, 이메일 인증, 카카오 로그인, 포인트
├── admin/       # 관리자 화면
└── _core/       # 설정, 인터셉터, 공통 오류 및 유틸리티

src/main/resources/
├── templates/   # Mustache 화면
├── application*.yaml
└── db/          # 초기 데이터
```
